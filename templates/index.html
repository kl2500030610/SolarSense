Solar Power Plant Exploratory Data Analysis

A web dashboard that loads the {{ dataset_name }} dataset, inspects its structure, and performs a complete exploratory data analysis with statistics and visualisations.

📥 Load Dataset

Load the combined solar dataset, inspect its shape, columns, data types, missing values and a preview of the rows.

📊 Perform EDA

Descriptive statistics, missing & duplicate analysis, numerical and categorical analysis, correlations, outliers and key findings.

📈 Regression

Supervised regression to predict AC power output using environmental conditions and plant ID. Model training, evaluation, and live prediction.

🌲 Ensemble Models

Tree-based ensemble methods: RandomForest, XGBoost, DecisionTree, and AdaBoost. Model comparison, feature importance, and live prediction.

🔍 Unsupervised Learning

Discover hidden structure: K-Means, hierarchical and DBSCAN clustering, PCA / t-SNE / UMAP dimensionality reduction, and Isolation Forest anomaly detection.

📐 Model Analysis

Cross-validation, train/validation/test splits, regression and classification metrics, probability calibration, and hyperparameter search (grid, random, Bayesian).

About the dataset

{{ dataset_name }} consists of four CSV files (generation and weather-sensor records for two solar plants). The records are sampled every 15 minutes between May 2020 and June 2020. Generation data includes per-inverter DC/AC power output and yield counters; weather data includes ambient/module temperature and irradiation. The web app combines all four files into a single analysis-ready dataset.
